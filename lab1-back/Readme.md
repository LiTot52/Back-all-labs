## Теоретическое обоснование

Бэкенд-разработка - это создание серверной части веб-приложения, которая обрабатывает запросы от клиентов, взаимодействует с базами данных, выполняет бизнес-логику и формирует ответы. Взаимодействие клиента и сервера строится по модели «клиент-сервер»: клиент (браузер, мобильное приложение) отправляет HTTP-запрос, а сервер принимает его, обрабатывает и возвращает HTTP-ответ.
 
Эндпоинт (endpoint) - это конкретный адрес (URL) вместе с HTTP-методом, по которому клиент обращается к серверу за ресурсом, например `GET /api/recipes`. Маршрут (route) - механизм, который сопоставляет путь запроса с кодом-обработчиком на сервере. В данной работе используется метод GET, который применяется исключительно для получения данных и не изменяет состояние сервера (свойство идемпотентности).
 
JSON (JavaScript Object Notation) - текстовый формат обмена данными, ставший стандартом для REST API благодаря простоте и читаемости. Для разработки использовались два стека: Node.js + Express (JavaScript) и Python + Flask - оба позволяют быстро создавать HTTP-серверы, обрабатывать маршруты и настраивать автоматический перезапуск при изменении кода (nodemon для Node.js, режим `debug=True` для Flask).

## Выполнение практического примера

### Node.js + Express
```js
from flask import Flask, jsonify, request
import time
app = Flask(__name__)


@app.before_request
def log_request():
    print(
        f"Received {request.method} request for {request.path} at {time.strftime('%Y-%m-%d %H:%M:%S')}")


@app.route('/')
def home():
    return 'Добро пожаловать на базовый сервер!'


@app.route('/api/status')
def status():
    return jsonify({"status": "ok", "framework": "Flask"})


@app.route('/api/info')
def info():
    return jsonify({"author": "Student", "version": "1.0.0"})


@app.route('/api/users/<int:user_id>')
def get_user(user_id):
    return jsonify({"message": "Информация о пользователе", "userId": user_id})


@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Маршрут не найден"}), 404


if __name__ == '__main__':
    app.run(port=3000, debug=True)

```

### Node.js + Express

```js

const express = require('express');
const app = express();
const port = 3000;

app.use((req, res, next) => {
	console.log(`[${new Date().toISOString()}] ${req.method} ${req.url}`);
	next();
});

app.get('/', (req, res) => {
	res.send('Добро пожаловать на сервер!');
});

app.get('/api/recipes', (req, res) => {
	res.json([
		{ id: 1, title: 'Борщ', chefId: 1 },
		{ id: 2, title: 'Паста Карбонара', chefId: 2 }
	]);
});

app.get('/api/chefs', (req, res) => {
	res.json([
		{ id: 1, name: 'Иван Петров', specialty: 'Русская кухня' },
		{ id: 2, name: 'Марио Росси', specialty: 'Итальянская кухня' }
	]);
});

app.get('/api/recipes/:id', (req, res) => {
	res.json({ requestedId: req.params.id, status: 'success' });
});

app.use((req, res) => {
	res.status(404).json({ error: 'Маршрут не найден' });
});

app.listen(port, () => {
	console.log(`Сервер запущен на http://localhost:${port}`);
});
```

```Python
from flask import Flask, jsonify, request
import time

app = Flask(__name__)
app.json.ensure_ascii = False


@app.before_request
def log_request():
    print(
        f"Received {request.method} request for {request.path} at {time.strftime('%Y-%m-%d %H:%M:%S')}")


@app.route('/')
def home():
    return 'Добро пожаловать на сервер!'


@app.route('/api/status')
def status():
    return jsonify({'status': 'OK', 'framework': 'Flask'})


@app.route('/api/recipes/')
def get_recipes():
    recipes = [
        {'id': 1, 'name': 'Паста Карбонара', 'ingredients': [
            'паста', 'бекон', 'яйца', 'сыр']},
        {'id': 2, 'name': 'Салат Цезарь', 'ingredients': [
            'салат', 'курица', 'пармезан', 'соус Цезарь']},
    ]

def get_chefs():
    chefs = [
        {'id': 1, 'name': 'Гордон Рамзи', 'specialty': 'Британская кухня'},
        {'id': 2, 'name': 'Джейми Оливер', 'specialty': 'Итальянская кухня'},
    ]
    return jsonify(chefs)


@app.route('/api/recipes/<int:recipe_id>')
def get_recipe(recipe_id):
    return jsonify({'message': 'Информация о рецепте', 'recipeId': recipe_id})


@app.errorhandler(404)
def not_found(error):
    return jsonify({'error': 'Маршрут не найден'}), 404

    app.run(port=3000, debug=True)
```

## Ответы на контрольные вопросы

1. Что такое клиент-серверная архитектура? - Клиент-серверная архитектура это модель взаимодействия компьютерных сетей, при котором запросы распределяются только с двумя основными компонентами, клиентом и сервером, которые между собой обмениваются Http запросами тем самым передавая и обратывая информацию.
   
2. Какой протокол используется для общения клиента и сервера в
вебе? - Http (HyperText Transfer Protocol)

3. Что такое эндпоинт (endpoint)? - Определённая Url ссылка, по которой клиент обращается к серверу для получения, какого-либо ресурса или информации.

4. Какую структуру имеет HTTP-запрос и HTTP-ответ? Что такое
код состояния (status code)? - Http(запрос) состоит из Метода(GET,POST,PUT,DELETE), Конечный URL, Версия Http. Http(ответ) состоит из версии Http, Код состояния, Текстовое описание.
Код состояния (status code) - это трёхзначное число в ответе сервера, которое показывает результат обработки запроса. По нему клиент понимает, всё прошло успешно или произошла ошибка.Они бывают (информационны),(Успех),(Переадресация), (Ошибка со стороны клиента), (Ошибка со стороны сервера).





5. Что такое JSON? Почему он популярен в веб-разработке? - JavaScript Object Notation - это тектовый формат обмена данными. Он легко читается человеком и быстро обрабатывается программами, что делает его универсальным стандартом для передачи информации между разными системами




6. Как запустить сервер на Node.js или Flask? - Установите Node.js, Инициализируйте проект, Установите фреймворк, Создайте файл с кодом сервера.
Установите Python, Создайте виртуальное окружение, Установите Flask, Создайте файл с кодом приложения.


7. Что такое автоматический перезапуск сервера и зачем он
нужен? Какой пакет используется для Node.js? - Автоматический перезапуск сервера - это механизм, который самостоятельно перезапускает приложение (сервер) при определённых событиях: сбое, изменении кода, превышении лимита памяти или перезагрузке системы. Это избавляет от ручного вмешательства и повышает стабильность работы сервиса.
Для Node.js в продакшене обычно используют PM2 - менеджер процессов с автоперезапуском, фоновым режимом, мониторингом, кластеризацией и автостартом.


8. Какие коды состояния HTTP вы знаете? За что отвечает код
404? - HTTP-коды делятся на 1xx (информационные), 2xx (успех), 3xx (перенаправление), 4xx (ошибка клиента) и 5xx (ошибка сервера), а код 404 (Not Found) означает, что сервер не нашёл ресурс по указанному адресу.

9. Что такое middleware в Express / декораторы запросов во Flask
(для продвинутого уровня)? - На продвинутом уровне и Express middleware, и Flask-хуки/декораторы решают одну задачу - перехватить запрос до или после обработчика, чтобы выполнить сквозную логику: аутентификацию, логирование, валидацию, CORS, сжатие, обработку ошибок.

10.Как получить параметр из URL-пути (например, ID
пользователя) в вашем фреймворке? - В Express параметр пути задаётся в маршруте через :, например:
```js
app.get('/users/:id', (req, res) => {
  const userId = req.params.id;
  res.send(`User ID: ${userId}`);
});

```

Во Flask параметр указывается в декораторе маршрута в угловых скобках и передаётся в функцию представления как аргумент:
```python
@app.route('/users/<int:user_id>')
def get_user(user_id):
    return f'User ID: {user_id}'
```
